微软已死
Microsoft is Dead

2008-10-05

几天前我突然意识到微软已经死了。我在和一个年轻的初创公司创始人谈论谷歌和微软有什么不同。

微软？他没说什么，但我看得出他不太相信有人会害怕微软。

微软从80年代末开始在软件世界投下了近20年的阴影。我记得在那之前是 IBM。我相信它们将永远统治世界。

但它已经过去了。我能感觉到。甚至没有人再害怕微软了。他们仍然赚很多钱——IBM 也是——但他们不再控制着这个行业。

微软是什么时候死的，死于什么？我知道他们在2001年还很危险，因为我当时写了一篇文章讨论他们是如何打压初创公司的。

是什么杀死了它们？我认为是四件事，它们同时发生在2000年代中期。

最明显的是谷歌。城里只能有一个老大，谷歌显然就是那个。谷歌是现在最危险的公司，微软不是。

谷歌是什么时候取得领先的？人们会倾向于把它推回到2004年8月的 IPO，但那时他们还没有引领潮流。真正的转折点是2004年末到2005年初推出的 Gmail。

Gmail 还展示了基于网页的软件如果你利用后来被称为'Ajax'的技术能做多少事。这触发了一整波新的网络初创公司。

讽刺的是，微软无意中帮助创造了 Ajax。Ajax 中的 x 来自 XMLHttpRequest 对象，它让浏览器在后台发出HTTP请求。这是微软在90年代末为 Outlook 的 Web 版本发明的。

Ajax 的另一个关键组件是 JavaScript，运行在浏览器中的编程语言。微软看到了 JavaScript 的危险并试图通过鼓励开发者使用他们自己专有的 VBScript 来对付它。但 VBScript 太糟糕了以至于人们坚持使用 JavaScript。

微软死亡的第三个原因是宽带互联网。现在任何在乎的人都可以有快速的互联网接入。管道越大，桌面操作系统的重要性就越低。

棺材上的最后一颗钉子来自一个出人意料的地方：苹果。多亏了 OS X，苹果以一种堪称奇迹的方式从死里复活。

当然苹果也在音乐上让微软疲于奔命，电视和手机即将跟进。

我很高兴微软死了。他们就像尼禄或康茂德——那种只有继承的权力才能让你变成的邪恶。因为记住，微软的垄断不是他们赢得的。它是由 IBM 犯的一个错误交到他们手里的。

当然，作为黑客我忍不住会想怎么能修好一个坏掉的东西。有没有什么办法让微软复活？

令人惊讶的事实是，才华横溢的黑客——危险地才华横溢的黑客——以一家花数十亿美元的公司的标准来看可以非常便宜地获得。

把所有好的'Web 2.0'初创公司都买下来。他们花的钱比买 Facebook 少得多就能基本上买下所有这些公司。

把它们都放在硅谷的一栋楼里，用铅屏蔽保护他们免受与雷德蒙德的任何接触。很抱歉用这么严厉的比喻，但这正是我的意思。让他们独立运作。不要试图'整合'他们的工作。

我已经知道对这篇文章的反应会是什么。一半的读者会说微软仍然是一家利润极高的公司，我怎么敢说它死了。另一半人会说我在陈述显而易见的事实。
