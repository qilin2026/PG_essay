N件事清单
The List of N Things

2009-09-01

我敢打赌当期的《Cosmopolitan》一定有一篇标题以数字开头的文章。'他不会告诉你的7件事关于性的事'之类的。

为什么读者这么喜欢 N 件事清单？主要是因为它比普通文章更容易阅读。从结构上说，N 件事清单和一篇文章是一样的。不同的是它们的结构是显式的。

阅读一篇文章的部分工作是理解它的结构——弄清楚高中时我们会叫做'提纲'的东西。在 N 件事清单中，提纲已经给出了。

除了是显式的，这种结构保证是最简单的类型：几个主要观点，只有很少的子层级。

因为主要观点是不相关联的，N 件事清单是随机访问的。你不需要跟踪一条贯穿整篇文章的论证线索。你可以跳过任何你觉得无聊或难以理解的观点。

有时候这种格式确实是作者想要的。一种显而易见的情况是你要说的确实就是一个列表。另一种是你想为自己写个清单，这在初创公司的世界里对我来说每天都在发生。

使用这种格式还有其他不太正当的理由。比如，当截止日期临近时我就用它。如果我找不到论证线索，我可以至少说些有用的话。

N 件事清单对作者和读者一样轻松。你在头5分钟就想出了 n/2 个。所以，砰，结构有了。你只需要填充就行了。

因为 N 件事清单对作者也更容易，当读者更喜欢它时并不总是一个坏信号。它不一定意味着读者只想看浅薄的东西。

因为 N 件事清单是最容易的文章形式，它应该是初学写作者的好形式。事实上确实如此。从本质上说，五段式论文其实就是 N 件事清单。

用 N 件事清单来入门学生似乎是个好计划。这是最容易的形式。但如果我们这样做，至少应该诚实地告诉学生这是怎么回事。我们应该告诉他们这只是一种练习形式，不是文章的理想形式。

N 件事清单有一个不诚实的用法：当你用它来虚假地声称你要总结整个主题来吸引注意力时。

如果你真的相信你已经做了一份详尽的清单，在数字前加'The'是没问题的。但证据表明大多数以'The'开头的清单根本不是详尽的。

N 件事清单最大的弱点是几乎没有新思考的空间。文章写作的要点是发现新想法，而这只能在你把想法串成一条论证线索时才会发生。

在 N 件事清单中这只能以非常有限的方式发生。你先定标题，那就是它最终的样子。你在列表格式中不太可能改变你文章的主题。

承认五段式论文实际上就是 N 件事清单的另一个好处是，我们可以停止假装它是正确的论文写作形式了。
