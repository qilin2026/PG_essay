一个拯救生命的 NFT
An NFT That Saves Lives

2021-01-01

Noora Health，一个我支持了多年的非营利组织，刚刚推出了一个新的 NFT。它有一个戏剧性的名字——拯救数千条生命——因为收益确实会做到这一点。

Noora 已经拯救生命七年了。他们在南亚的医院里运行项目，教新妈妈们在回家后如何照顾婴儿。他们现在已经进入了165家医院。由于他们知道进入新医院前后的数据，他们可以衡量自己的影响。这个影响是巨大的。每1000个活产婴儿中，他们挽救了9个婴儿的生命。

这个数字来自一项对28家不同医院133,733个家庭的研究，该研究由 Noora 与布莱根妇女医院和哈佛大学陈曾熙公共卫生学院联合中心 Ariadne Labs 的 Better Birth 团队合作进行。

Noora 如此高效，即使你用最保守的方式来衡量他们的成本——将他们的全部预算除以挽救的生命数量——挽救一条生命的成本也是我见过的最低的。1,235美元。

对于这个 NFT，他们将发布一份公开报告，追踪这笔特定资金的使用情况，并估算因此而挽救的生命数量。

NFT 是一个新领域，用这种方式使用它们尤其新颖，但我对它的潜力感到兴奋。我很期待看到这次特定拍卖会发生什么，因为与代表已经发生之事的 NFT 不同，这个 NFT 的价格越高就越好。

底价大约是250万美元，因为这是让名字成真所需要的：这是拯救2000条生命的成本。但这个 NFT 的价格越高，就会有越多的生命被挽救。能写出这样一句话，真是了不起。
