像说话一样写作
Write Like You Talk

2020-01-01

这里有一个简单的技巧，可以让更多人读你写的东西：用口语来写。

大多数人一开始写东西时，某种东西就会笼罩他们。他们用一种与和朋友交谈时不同的语言来写。句子结构和用词都不同。甚至连他们表达的想法也不同了。他们不会在谈话中说出一些学术垃圾，但当他们写下来时，他们就不再自我检查了。

最后一根稻草是我几天前读到的一句话：

那位多变的西班牙人亲自宣称：'阿尔塔米拉之后，一切都是颓废。'

那位多变的西班牙人亲自宣称：'阿尔塔米拉之后，一切都是颓废。'

这出自 Neil Oliver 的《古代不列颠史》。拿这本书当反面例子让我不好意思，因为它不比其他许多书更差。但试着想象一下把这句话当作对话来说。'那个多变的西班牙人亲自宣称'？你要是在对话中这么说，朋友们会笑你。

好吧，那么书面语和口语是不同的。这是否意味着书面语更差？

如果你希望人们阅读并理解你写的东西，是的。书面语更复杂，这使得阅读更费力。它也更正式，从而与读者产生距离。

你不需要复杂的句子来表达复杂的想法。当某个深奥领域的专家们互相谈论他们领域的想法时，他们不会使用比日常对话更复杂的句子。他们会使用不同的词汇，但即使是这些词汇，他们也不会去挑选那些华丽花哨的。

非正式的语言就是想法的运动服。

我不是说口语总是最好的。诗歌既是音乐也是文字，所以你可以说一些在对话中不会说的话。也有些修辞手法，如果用在对话中会显得做作，但在写作中却很有效，尤其是对于结尾。但对于大多数人来说，大多数时候，像说话一样写作是最好的策略。

对大多数人来说，用口语写作似乎很困难。所以也许最好的解决方案是按你平时的方式写初稿，然后逐句重写，问自己这是不是你在和朋友说话时会说的话。如果不是，想象一下你会怎么说，然后用那种方式来写。

在发表一篇新文章之前，我会把它大声朗读出来，修改一切听起来不像对话的地方。我甚至会修改语音上别扭的地方；我不知道还有谁这样做，但一个句子如果有太多爆破音接近在一起，我会觉得不好。

这个技巧可能并不总是够用。我见过一些写作离口语如此之远，以至于无法逐句修复。对于这种情况，我会建议更剧烈的措施。在你的写作之后，试着用正常的对话来解释你所说的内容。然后用你在对话中说的话代替原来的文字。

人们经常告诉我，我的文章读起来多么像我在说话。这件事看起来值得评论，说明人们多么少能做到用口语写作。如果让你想到的不是'多么不同寻常'，而是'为什么不呢？'，你就走在正确的道路上了。

如果你仅仅做到用口语来写作，你就会领先于95%的写作者。而且这很容易做到：只要不让任何你不会在对话中说的句子通过。用口语来写就行了。
